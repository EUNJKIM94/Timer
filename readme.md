# ⏱️ 대형 화면 스마트 타이머 웹앱 (Smart Timer WebApp)

본 프로젝트는 설치나 인터넷 접속 없이 브라우저에서 바로 동작하는 **대형 화면 스마트 타이머 웹앱**입니다. 빔프로젝터, 대형 TV, 대형 모니터 등 원거리 시인성이 필요한 행사, 경기, 강의, 발표 환경에 최적화되어 있습니다.

---

## 📄 파일 구성

* `index.html`: 타이머 프로그램 본체 (HTML, CSS, JS 일체형)
* `readme.md`: 웹앱 설명 및 설치/사용 안내 문서

---

## 🚀 빠른 시작 방법

### 1. 다운로드 및 실행
1. 웹앱 파일(`index.html`)을 다운로드하거나 원하는 폴더에 저장합니다.
2. `index.html` 파일을 **마우스 더블 클릭**하면 크롬(Chrome), 에지(Edge), 파이어폭스(Firefox) 등 원하시는 웹 브라우저에서 즉시 실행됩니다.

### 2. 전체 화면 전환 (권장)
* 브라우저에서 **`F11`** 키를 누르면 주소창과 메뉴바가 사라진 깔끔한 **전체 화면 모드**로 타이머를 띄울 수 있습니다.

---

## ✨ 주요 기능 및 특징

1. **우아한 골드 월계관(Wreath) & 아치 디자인**
   * 스포츠 챔피언십 및 공식 이벤트에 어울리는 고급스러운 월계관 그래픽과 아치형 텍스트 레이아웃을 제공합니다.

2. **독립된 3단계 컨트롤 버튼**
   * **`▶ 시작`**: 설정된 시간으로 카운트다운을 시작합니다.
   * **`❚❚ 일시정지`**: 진행 중인 타이머를 멈춥니다.
   * **`↺ 초기화`**: 타이머를 처음 설정값으로 리셋합니다.

3. **빠른 시간 선택 & 사용자 지정 입력**
   * **+5분 / +10분 / +15분** 빠른 클릭 버튼 제공
   * 원하는 분(Minute) 단위를 직접 입력하여 1초 단위로 완벽하게 적용 가능

4. **긴급 카운트다운 알림 (Urgent Effect)**
   * 남은 시간이 **10초 이하**가 되면 숫자가 빨간색 네온 컬러로 변경되며 펄스 애니메이션이 활성화됩니다.

5. **종료 알림 sound & 효과**
   * 카운트다운이 종료되면 축하 안내 문구와 함께 알림음(Beep Sound)이 울립니다.
